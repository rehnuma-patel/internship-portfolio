# Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

🌐 **Live site:** https://rehnuma-patel.github.io/internship-portfolio/

## Features
- Responsive layout (Flexbox + CSS Grid, mobile menu)
- Smooth scrolling and active navigation highlighting
- Typing animation, scroll-reveal and hover micro-animations
- Animated skill bars and project filtering
- Dark / light theme toggle (saved in localStorage)
- Contact form with client-side validation

## Sections
Home · About · Skills · Projects · Education & Experience · Achievements · Contact

## Mini Projects
- **[Password Strength Checker](projects/password-checker/)**: real-time strength meter, requirement checklist, estimated crack time and a secure password generator (Web Crypto API). Runs fully in the browser.
- **[Phishing Awareness Quiz](projects/phishing-quiz/)**: 8 realistic sample emails. Decide whether each is phishing or legitimate, then see the warning signs explained.

## Run locally
Open `index.html` in a browser, or use the VS Code **Live Server** extension.
